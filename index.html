Icon editor · your copy only

With Edit icons on, click any stratagem, booster, weapon, throwable or deed above to replace its picture. Right-click a replaced one to put the original back. Green outline = already replaced.

Icons you upload are kept only in the browser you uploaded them in. This button saves a new editor file with all your icons built into it. Open that file on your phone or any other computer and your icons are already there. Use it whenever you change icons.

Bulk upload matches each image to an icon by its file name. It understands the item's name with or without its designation (Eagle_500kg_Bomb.svg, Machine Gun Sentry.png), the weapon designation (AR-23.png, SG-97_Shotgun_Render.webp), and the id from the name list (e_500.png). Common extras like _Stratagem_Icon_Background, _Booster_Icon and _Primary_Render are ignored. Pick a whole folder and anything that isn't an icon is skipped.

For the GitHub site: Save icon pack for the site saves just your icons as icons.js. Upload it to the repo once; the site loads it automatically, and code updates to index.html never touch it. Save and upload it again whenever you change icons.

The locked copy has your icons built in. Nobody using it can replace icons or add their own gear — they can only build their card. Keep this file for yourself and share the locked one.
